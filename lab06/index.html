Значення деяких коефіцієнтів можуть дорівнювати нулю. Визначити і вивести на екран вирази, що є сумою двох многочленів, різницею двох многочленів, добутком двох многочленів. Врахувати можливість обробки многочленів різних степенів та наявності нульових коефіцієнтів при деяких членах.

Аналіз задач

Динамічні масиви в цій роботі не схвалюються, а розмір масиву відомий лише під час виконання. Тому в усіх програмах масиви мають фіксований найбільший розмір, а використовується тільки введена кількість елементів. У завданнях 1 і 2 це від 1 до 100 елементів. Елементи цілі. З клавіатури вводяться числа за модулем до 10000, а випадкові числа беруться від 0 до 29, щоб у них траплялися однакові значення. Некоректне введення повторюється в усіх програмах через функцію inputNumber. Індекси рахуються від 0.

Завдання 1, варіант 4

Функція findSmallestCommon проходить перший масив і запам'ятовує індекс найменшого елемента з тих, що знайшлися в другому. Індекс змінюється лише тоді, коли новий елемент строго менший, тому серед кількох однакових мінімумів лишається перший. Якщо індекс так і лишився -1, програма повідомляє, що однакових елементів немає.

Завдання 2, варіант 4

Сортування зроблено за алгоритмом Хоара, як у лекції. Опорним є середній елемент частини. Індекс i йде вправо до елемента, не меншого за опорний, а j йде вліво до елемента, не більшого за опорний. Ці два елементи міняються місцями. Коли індекси розійшлися, функція викликає себе для лівої і правої частини.

Лічильник порівнянь враховує лише порівняння елементів масиву з опорним. Обміном вважається справжній обмін двох різних позицій, тому при i = j лічильник не змінюється.

Бінарний пошук працює лише з відсортованим масивом, тому він виконується після сортування. Функція findValue порівнює шукане значення із середнім елементом частини, а потім викликає себе для лівої або правої половини. На один виклик припадає до двох порівнянь: на рівність і на менше. Якщо таких значень у масиві кілька, програма виводить індекс того, на яке вийшов пошук. Якщо частина порожня, функція повертає -1, і програма пише, що значення немає.

У режимі з проміжними ітераціями програма виводить межі частини, опорний елемент і масив після кожного обміну.

Завдання 3, варіант 4

Коефіцієнти цілі. Вони зберігаються так само, як у формулі: елемент з індексом i стоїть при xn-i, тому нульовий індекс відповідає старшому степеню. Степені вводяться від 3 до 10. Модуль коефіцієнта не більший за 1000, щоб коефіцієнти добутку вміщалися в int. Для випадкових коефіцієнтів вводяться нижня і верхня межі, причому верхня не може бути меншою за нижню.

Щоб додати многочлени різних степенів, коефіцієнти меншого зсуваються вправо на різницю степенів. Тоді коефіцієнти при однакових степенях стоять під одним індексом. У добутку aibj стоїть при xn+m-(i+j), тому він додається до коефіцієнта з індексом i + j.

ck = ∑i+j=k aibj, k = 0, ..., n + m

Під час виведення нульові доданки пропускаються. Знак першого доданка пишеться без пробілів, коефіцієнт 1 перед x не пишеться. Якщо всі коефіцієнти нульові, виводиться 0. Старший коефіцієнт теж може бути нульовим, тоді у виразі просто немає цього доданка.

/// <summary>
/// Лабораторна робота №6, завдання 1, варіант 4. Знайти найменший елемент
/// першого масиву серед тих, що збігаються з елементами другого масиву.

/// <remarks>
/// Ім'я файлу: task1.cpp

#include <cstdlib>
#include <ctime>

// Константи
const int MAX_SIZE = 100;    // найбільша кількість елементів масиву
const int MAX_VALUE = 10000; // найбільший модуль елемента з клавіатури

int secondSize = 0;              // кількість елементів другого масиву
int smallestIndex = -1;          // індекс знайденого елемента, -1 якщо немає

/// <summary>
/// Вводить ціле число. Поки введено не число або число поза межами, введення
/// повторюється
/// </summary>
/// <param name="minValue">найменше значення</param>
/// <param name="maxValue">найбільше</param>
/// <returns>введене число</returns>
int inputNumber(int minValue, int maxValue)
{
    int number = 0; // введене число

    cin >> number;
    while (cin.fail() || number < minValue || number > maxValue)
    {
        cin.clear();            // скинути помилку введення
        cin.ignore(1000, '\n'); // і пропустити неправильний рядок
        cout << "Error! Enter a number from " << minValue << " to " << maxValue
             << ": ";
        cin >> number;
    }

    return number;
}

/// <summary>
/// Вводить кількість елементів обох масивів
/// </summary>
void inputSizes()
{
    cout << "Enter size of the first array (from 1 to 100): ";
    firstSize = inputNumber(1, MAX_SIZE);

    cout << "Enter size of the second array (from 1 to 100): ";
    secondSize = inputNumber(1, MAX_SIZE);

/// <summary>
/// Вводить елементи масиву з клавіатури
/// </summary>
/// <param name="array">масив</param>
/// <param name="size">кількість елементів</param>
void enterArray(int array[], int size)
{
    int i = 0; // індекс елемента

    for (i = 0; i < size; i++)
    {
        cout << "Element " << i << " (from -10000 to 10000): ";
        array[i] = inputNumber(-MAX_VALUE, MAX_VALUE);
    }

/// <summary>
/// Заповнює масив псевдовипадковими числами

void generateArray(int array[], int size)
{
    int i = 0; // індекс елемента

/// <summary>
/// Виводить меню і створює масиви вибраним способом

/// <summary>
/// Виводить елементи масиву в один рядок
/// </summary>
/// <param name="array">масив</param>
/// <param name="size">кількість елементів</param>
void printArray(int array[], int size)
{
    int i = 0; // індекс елемента

    for (i = 0; i < size; i++)
    {
        cout << array[i] << " ";
    }
    cout << endl;
}

/// <summary>
/// Перевіряє, чи є значення в другому масиві
/// </summary>
/// <param name="value">значення, яке шукаємо</param>
/// <returns>true, якщо значення є в другому масиві</returns>
bool isInSecondArray(int value)
{
    bool isFound = false; // чи знайдено значення
    int i = 0;            // індекс елемента

    for (i = 0; i < secondSize; i++)
    {
        if (secondArray[i] == value)
        {
            isFound = true;
        }
    }

    return isFound;
}

/// <summary>
/// Шукає в першому масиві найменший елемент, який є в другому масиві. Менший
/// елемент замінює знайдений, тому серед однакових мінімумів лишається перший
/// </summary>
void findSmallestCommon()
{
    int i = 0; // індекс елемента першого масиву

    for (i = 0; i < firstSize; i++)
    {
        if (isInSecondArray(firstArray[i]))
        {
            if (smallestIndex == -1
                || firstArray[i] < firstArray[smallestIndex])
            {
                smallestIndex = i;
            }
        }
    }
}

/// <summary>
/// Виводить обидва масиви і результат пошуку
/// </summary>
void printResult()
{
    cout << endl << "First array:  ";
    printArray(firstArray, firstSize);
    cout << "Second array: ";
    printArray(secondArray, secondSize);

    if (smallestIndex == -1)
    {
        cout << "The arrays have no equal elements." << endl;
    }
    else
    {
        cout << "Smallest common element: " << firstArray[smallestIndex]
             << endl;
        cout << "Its index in the first array: " << smallestIndex << endl;
    }
}

/// <summary>
/// Головна функція програми
/// </summary>
/// <returns>0 після завершення роботи</returns>
int main()
{
    printTitle();
    inputSizes();
    createArrays();
    findSmallestCommon();
    printResult();
    return 0;
}

/// <summary>
/// Сортує частину масиву за алгоритмом Хоара і рахує порівняння елементів та
/// обміни
/// </summary>
/// <param name="left">індекс початку частини</param>
/// <param name="right">індекс її кінця</param>
void quickSort(int left, int right)
{
    int i = left;                            // індекс, що йде вправо
    int j = right;                           // індекс, що йде вліво
    int pivot = numbers[(left + right) / 2]; // опорний елемент
    int temp = 0;                            // змінна для обміну

    if (isDetailed)
    {
        cout << "left = " << left << ", right = " << right
             << ", pivot = " << pivot << endl;
    }

    do
    {
        sortCompareCount++;
        while (numbers[i] < pivot)
        {
            i++;
            sortCompareCount++;
        }

        sortCompareCount++;
        while (numbers[j] > pivot)
        {
            j--;
            sortCompareCount++;
        }

        if (i < j)
        {
            temp = numbers[i];
            numbers[i] = numbers[j];
            numbers[j] = temp;
            swapCount++;

            if (isDetailed)
            {
                printArray();
            }
        }

        if (i <= j)
        {
            i++;
            j--;
        }
    } while (i <= j);

    if (left < j)
    {
        quickSort(left, j);
    }
    if (i < right)
    {
        quickSort(i, right);
    }
}

/// <summary>
/// Шукає значення target у частині відсортованого масиву: порівнює його із
/// середнім елементом і викликає себе для лівої або правої половини
/// </summary>
/// <param name="left">індекс початку частини</param>
/// <param name="right">індекс її кінця</param>
/// <returns>індекс знайденого елемента, або -1</returns>
int findValue(int left, int right)
{
    int index = -1; // індекс знайденого елемента
    int middle = 0; // індекс середнього елемента

    if (left <= right)
    {
        middle = (left + right) / 2;
        searchCompareCount++;

        if (numbers[middle] == target)
        {
            index = middle;

        else

            {
                index = findValue(left, middle - 1);
            }
            else
            {
                index = findValue(middle + 1, right);
            }
        }
    }

    return index;
}

/// <summary>
/// Обчислює суму і різницю. Менший многочлен зсувається вправо, щоб коефіцієнти
/// при однакових степенях стояли під одним індексом
/// </summary>
void calculateSumAndDifference()
{
    int i = 0;     // індекс коефіцієнта
    int shift = 0; // зсув індексів

    largerDegree = firstDegree;
    if (secondDegree > largerDegree)
    {
        largerDegree = secondDegree;
    }

    shift = largerDegree - firstDegree;
    for (i = 0; i <= firstDegree; i++)
    {
        sum[i + shift] = firstPolynomial[i];
        difference[i + shift] = firstPolynomial[i];
    }

    shift = largerDegree - secondDegree;
    for (i = 0; i <= secondDegree; i++)
    {
        sum[i + shift] = sum[i + shift] + secondPolynomial[i];
        difference[i + shift] = difference[i + shift] - secondPolynomial[i];
    }
}

/// <summary>
/// Обчислює добуток: кожен коефіцієнт першого многочлена множиться на кожен
/// коефіцієнт другого
/// </summary>
void calculateProduct()
{
    int i = 0; // індекс коефіцієнта першого многочлена
    int j = 0; // індекс коефіцієнта другого многочлена

    for (i = 0; i <= firstDegree; i++)
    {
        for (j = 0; j <= secondDegree; j++)
        {
            product[i + j] =
                product[i + j] + firstPolynomial[i] * secondPolynomial[j];
        }
    }
}

/// <summary>

/// <param name="coefficient">коефіцієнт</param>
/// <param name="power">степінь x</param>
/// <param name="isFirst">чи це перший доданок виразу</param>
void printTerm(int coefficient, int power, bool isFirst)
{
    if (coefficient < 0)
    {
        if (isFirst)
        {
            cout << "-";
        }
        else
        {
            cout << " - ";
        }
    }
    else if (!isFirst)

        cout << abs(coefficient);
    }

    if (power == 1)
    {
        cout << "x";
    }
    else if (power > 1)
    {
        cout << "x^" << power;
    }
}

/// <summary>
/// Виводить многочлен без нульових доданків. Якщо всі коефіцієнти нульові,
/// виводить 0
/// </summary>

    }

}
