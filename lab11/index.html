Умови задач

Завдання 1, варіант 4.1

У таблиці методички 24 варіанти, тому для номера 28 у списку групи маємо 28 - 24 = 4.

Увести з клавіатури рядки і записати їх у текстовий файл. У кожному непарному рядку визначити слово, що має найбільшу кількість голосних. Дописати знайдені слова в кінець кожного рядка файлу.

Вимоги методички до завдання:

  • програма складається з функцій, основна програма викликає їх залежно від вибору в меню;
  • меню команд виконує окремі операції з обробки файлу;
  • текстовий файл створюється введенням даних з клавіатури;
  • вміст файлу виводиться на екран;
  • у кожній функції вхідні файли відкриваються, а вихідні закриваються;
  • рядки обробляються в окремих функціях, без STL, через string.h;
  • файли обробляються через класи потоків або через функції stdio.h, за обидва інструменти разом бал найвищий.

Аналіз задач

Завдання 1, варіант 4.1

Програма записує рядки з клавіатури у файл text.txt. Рядки нумеруються з 1. Голосними вважаються a, e, i, o, u, y, великі й малі, бо тексти англійські. Слова розділяються пробілом, табуляцією або знаками , . ; : ! ?. Якщо кілька слів мають однакову кількість голосних, береться перше з них. Якщо в рядку немає слів, до нього нічого не дописується.

В умові сказано дописати слова в кінець кожного рядка, але шукаються вони лише в непарних рядках. Тому кожне знайдене слово дописується в кінець свого непарного рядка, а парні рядки не змінюються.

Файли обробляються через fstream. Рядок усередині файлу не можна подовжити, тому програма переписує всі рядки в text.tmp, а потім видаляє початковий файл і дає тимчасовому його ім'я. Рядок ділиться на слова функцією strtok, голосні шукає strchr, слово дописує strcat. Масив для рядка файлу вміщає 255 символів, тому слово дописується лише тоді, коли вміщається. Кожен вибір пункту 3 дописує слова ще раз.

Кількість рядків вводиться від 1 до 20, рядок має до 80 символів. Некоректну кількість і задовгий рядок програма просить ввести ще раз. Якщо файлу немає, виводиться повідомлення.

Завдання 2, варіант 3.2

За основу взято програму лабораторної роботи №10. Поля запису, генерація, правила для відмінників і двієчників, ключі запитів лишилися ті самі. Після створення масив записується у файл journal.dat, а таблиця друкується вже з файлу. Файли обробляються функціями fopen, fread, fwrite, fseek, fclose зі stdio.h. Разом із потоками в завданні 1 це обидва інструменти, які називає методичка.

Один запис займає 64 байти: три текстові поля по 16 байтів, курс 4 байти і три оцінки по 4 байти. Номер запису вибирається за таблицею, яку програма виводить перед вибором.

Новий запис дописується в режимі ab. Заміна відкриває файл у режимі r+b, переміщує покажчик функцією fseek на місце вибраного запису і пише поверх нього. Обидві дії робить функція writeRecord. Для видалення файл читається в масив, наступні записи зсуваються на одне місце вперед, і масив записується у файл заново. Файл вміщає до 30 записів, більше програма не дописує.

Запити працюють так само, як у лабораторній роботі №10, але дані спершу читаються з journal.dat. Результат кожного запиту записується в новий бінарний файл: best.dat, excellent.dat або groups.dat. Потім програма читає цей файл і виводить таблицю. Усі файли мають той самий формат запису. У best.dat і groups.dat лежить перший запис знайденої пари чи групи, а на екран виводяться лише факультет, курс і група.

Якщо файл не вдалося відкрити, програма виводить повідомлення. Якщо journal.dat ще немає, таблиця і запити дають порожній результат, а додавання запису створює файл.

/// <summary>
/// Лабораторна робота №11, завдання 1, варіант 4.1. Записати рядки у текстовий
/// файл і дописати в кінець кожного непарного рядка слово з найбільшою

const int MAX_LINES = 20;              // найбільша кількість рядків

/// <summary>
/// Вводить кількість рядків файлу і забирає кінець рядка, щоб після неї

/// <summary>
/// Рахує голосні літери в слові
/// </summary>
/// <param name="word">слово</param>
/// <returns>кількість голосних</returns>
int countVowels(char word[])
{
    int count = 0;             // кількість голосних
    int length = strlen(word); // довжина слова
    int i = 0;                 // номер літери

    for (i = 0; i < length; i++)
    {
        if (strchr(VOWELS, word[i]) != NULL)
        {
            count++;
        }
    }

    return count;
}

/// <summary>
/// Шукає в рядку слово з найбільшою кількістю голосних. Копія рядка потрібна
/// тому, що strtok псує рядок, який ділить на слова
/// </summary>
/// <param name="line">рядок</param>
/// <param name="bestWord">масив для знайденого слова</param>
void findBestWord(char line[], char bestWord[])
{
    char lineCopy[LINE_SIZE] = ""; // копія рядка
    char* word = NULL;             // поточне слово
    int vowelCount = 0;            // голосні поточного слова
    int maxVowels = -1;            // найбільша кількість голосних

    strcpy(bestWord, "");
    strcpy(lineCopy, line);
    word = strtok(lineCopy, SEPARATORS);

    while (word != NULL)
    {
        vowelCount = countVowels(word);
        if (vowelCount > maxVowels)
        {
            maxVowels = vowelCount;
            strcpy(bestWord, word);
        }
        word = strtok(NULL, SEPARATORS);
    }
}

/// <summary>
/// Дописує до рядка знайдене слово, якщо воно є і вміщається в рядок
/// </summary>
/// <param name="line">рядок</param>
/// <param name="lineNumber">номер рядка для повідомлення</param>
void appendBestWord(char line[], int lineNumber)
{
    char bestWord[LINE_SIZE] = ""; // знайдене слово

    findBestWord(line, bestWord);

    if (strlen(bestWord) > 0 && strlen(line) + strlen(bestWord) + 1 < LINE_SIZE)
    {
        strcat(line, " ");
        strcat(line, bestWord);
        cout << "Line " << lineNumber << ": " << bestWord << endl;
    }
}

/// <summary>
/// Переписує файл у тимчасовий, дописуючи слова до непарних рядків, а потім
/// ставить тимчасовий файл на місце початкового
/// </summary>
void processFile()
{
    char line[LINE_SIZE] = ""; // прочитаний рядок
    int lineNumber = 0;        // номер рядка
    ifstream input(FILE_NAME); // початковий файл
    ofstream output;           // тимчасовий файл

    if (!input.is_open())
    {
        cout << "File not found. Create it first." << endl;
    }
    else
    {
        output.open(TEMP_NAME);
        while (input.getline(line, LINE_SIZE))
        {
            lineNumber++;
            if (lineNumber % 2 == 1)
            {
                appendBestWord(line, lineNumber);
            }
            output << line << endl;
        }
        input.close();
        output.close();

        remove(FILE_NAME);
        rename(TEMP_NAME, FILE_NAME);
    }
}

/// <summary>
/// Показує меню і викликає вибрані дії, поки не вибрано вихід
/// </summary>
void runMenu()
{
    int choice = -1; // вибраний пункт меню

    while (choice != 0)
    {
        cout << endl << "1. Create file from keyboard" << endl;
        cout << "2. Print file" << endl;
        cout << "3. Append found words to odd lines" << endl;
        cout << "0. Exit" << endl;
        cout << "Choose menu item: ";

        cin >> choice;
        if (cin.fail())
        {
            cin.clear();
            choice = -1;
        }
        cin.ignore(1000, '\n');

        switch (choice)
        {
            case 1 : createFile(); break;
            case 2 : printFile(); break;
            case 3 : processFile(); break;
            case 0 : break;
            default : cout << "No such menu item." << endl;
        }
    }
}

/// <summary>

/// <summary>
/// Створює випадковий запис. Найнижча оцінка студента теж випадкова, тому серед
/// записів є і відмінники, і студенти з двійками
/// </summary>
/// <returns>заповнена структура</returns>
StudentRecord generateRecord()
{
    StudentRecord record = {};                 // новий запис
    int facultyIndex = rand() % FACULTY_COUNT; // номер факультету
    int suffixIndex = rand() % SUFFIX_COUNT;   // номер закінчення групи
    // найнижча оцінка студента
    int lowestGrade = FAIL_GRADE + rand() % (TOP_GRADE - FAIL_GRADE + 1);
    int i = 0; // номер іспиту

    strcpy(record.faculty, FACULTIES[facultyIndex]);
    record.course = suffixIndex / 2 + 1;
    strcpy(record.group, FACULTIES[facultyIndex]);
    strcat(record.group, SUFFIXES[suffixIndex]);
    strcpy(record.surname, SURNAMES[rand() % SURNAME_COUNT]);

    for (i = 0; i < EXAM_COUNT; i++)
    {
        record.grades[i] = lowestGrade + rand() % (TOP_GRADE - lowestGrade + 1);
    }

    return record;
}

/// <summary>
/// Записує масив записів у бінарний файл
/// </summary>
/// <param name="fileName">ім'я файлу</param>
/// <param name="list">покажчик на масив</param>
/// <param name="size">кількість записів</param>
void saveRecords(const char fileName[], StudentRecord* list, int size)
{
    FILE* file = fopen(fileName, "wb"); // файл для запису

    if (file == NULL)
    {
        cout << "Cannot open file " << fileName << endl;
    }
    else
    {
        fwrite(list, sizeof(StudentRecord), size, file);
        fclose(file);
    }
}

/// <summary>
/// Читає записи з бінарного файлу в масив
/// </summary>
/// <param name="fileName">ім'я файлу</param>
/// <param name="list">покажчик на масив</param>
/// <returns>кількість прочитаних записів</returns>
int loadRecords(const char fileName[], StudentRecord* list)
{
    FILE* file = fopen(fileName, "rb"); // файл для читання
    int size = 0;                       // кількість записів

    if (file == NULL)
    {
        cout << "File " << fileName << " not found." << endl;
    }
    else
    {
        size = fread(list, sizeof(StudentRecord), MAX_RECORDS, file);
        fclose(file);
    }

    return size;
}

/// <summary>
/// Створює масив, записує його у файл і виводить таблицю з файлу
/// </summary>
/// <param name="isRandom">true, якщо записи генеруються</param>
void createJournal(bool isRandom)
{
    int i = 0; // номер запису

    cout << "Enter number of records (from 1 to " << MAX_RECORDS << "): ";
    recordCount = inputNumber(1, MAX_RECORDS);

    for (i = 0; i < recordCount; i++)
    {
        if (isRandom)
        {
            journal[i] = generateRecord();
        }
        else
        {
            journal[i] = readRecord(i + 1);
        }
    }

    saveRecords(JOURNAL_FILE, journal, recordCount);
    printFile();
}

/// <summary>
/// Вводить новий запис і пише його у файл на задане місце. У режимі "ab" запис
/// завжди потрапляє в кінець файлу, у режимі "r+b" заміняє старий
/// </summary>
/// <param name="mode">режим відкриття файлу</param>
/// <param name="index">номер місця від нуля</param>
void writeRecord(const char mode[], int index)
{
    StudentRecord newRecord = readRecord(index + 1); // новий запис
    FILE* file = fopen(JOURNAL_FILE, mode);          // файл для запису

    if (file == NULL)
    {
        cout << "Cannot open file " << JOURNAL_FILE << endl;
    }
    else
    {
        fseek(file, index * sizeof(StudentRecord), SEEK_SET);
        fwrite(&newRecord, sizeof(StudentRecord), 1, file);
        fclose(file);
    }
}

/// <summary>

int countGrades(StudentRecord record, int grade)
{
    int count = 0; // кількість оцінок
    int i = 0;     // номер іспиту

    for (i = 0; i < EXAM_COUNT; i++)

/// <summary>
/// Знаходить перший запис масиву з тим самим факультетом і курсом, що в
/// заданого запису, а якщо isWholeCourse = false, то й з тією самою групою
/// </summary>
/// <param name="index">номер запису</param>
/// <param name="isWholeCourse">чи не враховувати групу</param>
/// <returns>номер першого такого запису</returns>
int findFirst(int index, bool isWholeCourse)
{
    int first = 0;        // номер запису, що перевіряється
    bool isFound = false; // чи знайдено запис

    while (!isFound)
    {
        if (strcmp(journal[first].faculty, journal[index].faculty) == 0
            && journal[first].course == journal[index].course
            && (isWholeCourse
                || strcmp(journal[first].group, journal[index].group) == 0))
        {
            isFound = true;
        }
        else
        {
            first++;
        }
    }

    return first;
}

/// <summary>
/// Запит 1. Читає файл, рахує відмінників кожної пари "факультет, курс"
/// (лічильник лежить у першому записі пари), відбирає пари з найбільшою
/// кількістю, пише їх у файл результату і виводить цей файл
/// </summary>
void findBestCourses()
{
    StudentRecord results[MAX_RECORDS]; // перші записи знайдених пар
    int counts[MAX_RECORDS] = {};       // лічильники відмінників
    int maxCount = 0;                   // найбільша кількість
    int first = 0;                      // перший запис пари
    int size = 0;                       // кількість знайдених пар
    int i = 0;                          // номер запису

    recordCount = loadRecords(JOURNAL_FILE, journal);

    for (i = 0; i < recordCount; i++)
    {
        if (countGrades(journal[i], TOP_GRADE) == EXAM_COUNT)
        {
            first = findFirst(i, true);
            counts[first]++;
            if (counts[first] > maxCount)
            {
                maxCount = counts[first];
            }
        }
    }

    for (i = 0; i < recordCount; i++)
    {
        if (maxCount > 0 && counts[i] == maxCount)
        {
            results[size] = journal[i];
            strcpy(results[size].group, "all");
            size++;
        }
    }

    saveRecords(BEST_FILE, results, size);
    size = loadRecords(BEST_FILE, results);
    cout << "Maximum number of excellent students: " << maxCount << endl;
    printGroups(results, size);
}

/// <summary>
/// Запит 3. Читає файл, позначає групи, де є двійка (ознака лежить у першому
/// записі групи), відбирає решту груп заданого курсу, пише їх у файл результату
/// і виводить цей файл
/// </summary>
void findCleanGroups()
{
    StudentRecord results[MAX_RECORDS]; // перші записи знайдених груп
    bool hasFail[MAX_RECORDS] = {};     // чи є двійка в групі
    int course = 0;                     // ключ пошуку
    int size = 0;                       // кількість знайдених груп
    int i = 0;                          // номер запису

    recordCount = loadRecords(JOURNAL_FILE, journal);
    cout << "Enter course (from 1 to " << MAX_COURSE << "): ";
    course = inputNumber(1, MAX_COURSE);

    for (i = 0; i < recordCount; i++)
    {
        if (countGrades(journal[i], FAIL_GRADE) > 0)
        {
            hasFail[findFirst(i, false)] = true;
        }
    }

    for (i = 0; i < recordCount; i++)
    {
        if (journal[i].course == course && findFirst(i, false) == i
            && !hasFail[i])
        {
            results[size] = journal[i];
            size++;
        }
    }

    saveRecords(GROUPS_FILE, results, size);
    size = loadRecords(GROUPS_FILE, results);
    printGroups(results, size);
}
